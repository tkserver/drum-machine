# Drum Machine

Professional 8-bit drum machine with pattern sequencing and arrangement tools.

## Features

- **16-Voice Drum Machine**: Classic 8-bit drum sounds.
- **Pattern Sequencer**: Create and edit patterns with ease.
- **Arrangement Mode**: Chain patterns together to create full songs.
- **Mixer**: Control volume and pan for each track.
- **Keyboard Shortcuts**: Jam along with your keyboard.
- **Import/Export**: Save and load your patterns.
